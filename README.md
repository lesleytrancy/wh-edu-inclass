# 武侯课教智慧课堂

面向课堂教学的 React/Vite 演示系统，提供教师端、学生端和教室大屏，以“喀斯特地貌”课程演示资料准备、练习、提问、小组讨论和复盘。当前版本为 2.0.0。

三端使用同一浏览器、同一源的多个标签页联动。资料解析、普通提问和 AI 对话主要为预设演示逻辑；小组讨论支持浏览器原生录音和可用的语音识别。没有后端服务、真实模型 API 或 SQLite 数据库。

## 快速开始

需要 Node.js **20.19.x 及以上的 20.x，或 22.12.0 及以上**，以及 npm。该范围来自当前锁定的 Vite 依赖；本次验证环境为 Node 20.20.2 / npm 10.8.2。

```sh
npm ci
npm run dev
```

打开终端输出的本地地址，默认是 `http://localhost:5173`。若端口已占用，以终端实际地址为准，三个端使用相同地址。安装需要下载依赖；没有环境变量或模型密钥配置步骤。

| 页面 | 默认开发入口 |
| --- | --- |
| 控制台 | `http://localhost:5173/` |
| 教师端 | `http://localhost:5173/?view=teacher` |
| 学生端 | `http://localhost:5173/?view=student` |
| 教室大屏 | `http://localhost:5173/?view=screen` |

在三个标签页分别打开教师、学生和大屏。更改协议、主机或端口会形成不同的本地存储与同步范围；`localhost` 和 `127.0.0.1` 也不能混用。

### 常用命令

```sh
npm test
npm run build
npm run preview
```

测试使用 Node 内置测试运行器。默认生产构建输出至 `dist/`；预览地址以终端为准，通常为 `http://localhost:4173`。生产使用静态 Web 服务器托管 `dist/`，应用入口需要 HTTP/HTTPS，不能直接双击根目录 `index.html` 运行。

`package.json` 使用 `latest` 依赖范围，`npm ci` 按 `package-lock.json` 安装；更新依赖时应同时更新锁文件并重新运行测试和构建。

## 演示流程

1. 教师进入“资料管理”，上传 PDF 或图片作为课中展示资料。系统保存原文件并自动模拟生成预习、复习各两道习题及默认讨论题；不读取文件正文或生成 PPT。PPT/PPTX、Word、文本等也可保存，但直接展示需先导出 PDF 或图片。
2. 教师查看“课前预习”与“课后复习”，检查每名学生的逐题回答。当前列表前两名有模拟记录，其他学生初始未提交；重新解析会保留已有回答。
3. 学生登录，在“课前预习”完成全部选择题后提交；教师查看标记为“学生实际提交”的记录和正误。
4. 教师点击“开始上课”，学生切换到课堂互动，大屏展示选定课件。教师可使用“PPT 批注”或“展开白板”书写和清空当前画布层，笔迹不跨端同步或保存。
5. 点击提问按钮体验模拟录音，或把提问按钮拖到课件区域体验模拟快照出题。普通提问默认 15 秒，学生点击麦克风产生模拟文字，教师或大屏可提前停止；约 1.8 秒后展示预设分析结果。
6. 点击“小组讨论”，编辑问题并让学生选组。组长加入自己的组，可用文字或真实录音转写组织回答；教师点击“开始讨论 · 5 分钟”后回答自动同步。普通组员只能查看本组回答。手动结束或到时后按组整理总结，未回答组显示“暂无回答”。
7. 教师从“地理工具集”选择喀斯特地貌、太阳系、洋流、等高线或经纬图。工具覆盖教师课件区域，期间隐藏提问和讨论入口；点击“返回课中”恢复课件。工具选择不联动大屏。
8. 教师点击“结束上课”，学生切换到复习。返回教师课堂区域，在助教中点击“生成课堂报告”，然后点击“下载 / 打印 PDF”，在浏览器打印对话框选择“另存为 PDF”。报告是按当前状态渲染的示例视图，不会自动生成或保存独立 PDF 文件。

教师可在“班级管理”新增学生、改名和删除。学号不可手动修改，由当前名册最大编号加一生成；删除最大编号后可能复用编号。助教侧栏支持收起/展开，教师助教及学生学伴回复均为预设文案。

## 数据与同步

| 存储位置 | 名称 | 保存内容 |
| --- | --- | --- |
| localStorage | `wh-students` | 学生名册与演示状态 |
| localStorage | `wh-classroom` | 课堂阶段、资料元信息、学习包、答题和讨论状态 |
| localStorage | `wh-messages` | 教师与助教消息 |
| IndexedDB | 数据库 `wh-materials` / 对象库 `files` | 上传原始文件 |
| BroadcastChannel | 通道 `wh-classroom` | 完整课堂状态广播 |

课堂阶段、练习答案与讨论状态同步到同源标签页。学生名册、教师消息未专门实时广播；学生学伴对话、教师笔迹、工具选择和录音属于各页面本地状态。跨设备和跨浏览器没有同步；多个页面同时修改完整课堂状态可能互相覆盖，没有服务端并发控制。

### 重置演示数据

重置会删除当前源下的课堂记录和上传文件。先关闭该应用的其他标签页，在保留页面的浏览器开发者工具中：

1. 打开 Application/应用的 Local Storage/本地存储，删除 `wh-students`、`wh-classroom`、`wh-messages` 三个键。
2. 在 IndexedDB 中删除数据库 `wh-materials`；若提示占用，关闭应用页面后完成删除。
3. 重新打开应用，恢复三名初始学生和课前状态，再上传资料。

仅删除课堂元信息不会清除原始文件；仅删除 IndexedDB 会使现有元信息指向缺失素材，需要重新上传。不同端口、开发与预览地址的数据分别保存，需在对应源下操作。

## 浏览器要求与已知限制

- 使用支持 localStorage、IndexedDB 和 BroadcastChannel 的现代浏览器。无 BroadcastChannel 时界面仍可运行，但标签页课堂状态不会实时同步；原文件读取缺失时页面会提示重新上传。
- 讨论录音需要 localhost 或 HTTPS 与麦克风授权。语音识别依赖浏览器支持，可能使用在线服务；失败可用文字补充。停止后的音频可本机播放和下载，不持久化到数据库，不跨端同步。
- PDF 查看与“另存为 PDF”依赖浏览器功能。没有应用级 PPT 渲染、PDF 页码控制、翻页提示或最后一页检测，授课中可以直接结束课堂。
- 预习、复习、默认问题、普通提问录音/快照识别、普通学生提问回答和 AI 对话为模拟逻辑。92%、88%、82% 与开始课堂提示中的预习完成率 100% 是演示值，不是实际学习统计。
- 没有多班级管理、资源文件夹、确认发送流程、独立 Agent JSON 协议、自动持久化报告或服务端认证。原始需求差距见 [系统规格](spec/spec.md)。
- 数据保存在当前浏览器，没有备份或跨设备恢复；前端姓名学号校验与组长限制用于演示，不能作为正式部署的权限保障。
- `tools/` 内 HTML 含较多内嵌资源，生产构建可能提示输出块较大。应用依赖安装和浏览器语音服务可能联网，未验证所有工具的运行期请求，不承诺整套系统完全离线。
