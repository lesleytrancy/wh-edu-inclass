# 武侯课教智慧课堂

面向课堂教学的 React/Vite 系统，提供教师端、学生端和教室大屏，以“喀斯特地貌”课程演示资料准备、练习、提问、小组讨论和复盘。当前版本为 2.0.0，并提供可选的 FastAPI AI 服务；服务未启动或模型未配置时自动使用原有模拟逻辑。

三端可通过后端实时同步课堂状态，也支持同一浏览器的多个标签页联动。启用 AI 服务后，资料解析、三题制学习包、快照出题、习题分析和 AI 对话使用真实资料与豆包模型。小组讨论支持浏览器原生录音和自动续连的语音识别。

## 快速开始

需要 Node.js **20.19.x 及以上的 20.x，或 22.12.0 及以上**，以及 npm。该范围来自当前锁定的 Vite 依赖；本次验证环境为 Node 20.20.2 / npm 10.8.2。

```sh
npm ci
npm run dev
```

`npm run dev` 会同时启动 FastAPI（8000）和 Vite（默认 5173）。只需前端演示时可运行 `npm run dev:web`。

打开终端输出的本地 HTTP 地址，默认是 `http://localhost:5173`。不要把本地地址改成 `https://`，否则浏览器会显示 `ERR_SSL_PROTOCOL_ERROR`。端口占用时以终端实际端口为准。三个端必须使用相同的协议、主机和端口。只运行前端不需要环境变量或模型密钥；真实 AI 接入见下方“AI 服务”。

### 远程连接（内网穿透）

先启动 `npm run dev`，确认 Vite 使用 5173 端口后运行 `npm run dev:tunnel`。终端会给出 HTTPS 临时地址，教师和学生端使用该地址即可访问同一课堂。若 Vite 改用其他端口，应把 `dev:tunnel` 命令中的端口改为实际端口。生产部署建议使用已认证的 named tunnel，并把 `VITE_AI_API_BASE` 指向可访问的服务端地址。

| 页面 | 默认开发入口 |
| --- | --- |
| 控制台 | `http://localhost:5173/` |
| 教师端 | `http://localhost:5173/?view=teacher` |
| 学生端 | `http://localhost:5173/?view=student` |
| 教室大屏 | `http://localhost:5173/?view=screen` |

在三个标签页分别打开教师、学生和大屏。更改协议、主机或端口会形成不同的本地存储与同步范围；`localhost` 和 `127.0.0.1` 也不能混用。

```sh
npm test

```

测试使用 Node 内置测试运行器。默认生产构建输出至 `dist/`；预览地址以终端为准，通常为 `http://localhost:4173`。生产使用静态 Web 服务器托管 `dist/`，应用入口需要 HTTP/HTTPS，不能直接双击根目录 `index.html` 运行。

## AI 服务

AI 服务负责 MarkItDown 资料解析、SQLite/FTS5 检索、学习包草稿、教师助教、学生学伴和课堂回答分析。AI 生成的学习包仍需教师在页面检查并点击“发送学生端”后生效。

```sh
python3 -m venv .venv
.venv/bin/pip install -r server/requirements.txt
cp .env.example .env
# 在 .env 中填写 DOUBAO_API_KEY 和 DOUBAO_MODEL
.venv/bin/uvicorn server.app:app --reload --env-file .env
```

运行 `npm run dev` 会同时启动服务端和前端。Vite 会把 `/api` 代理到 `http://127.0.0.1:8000`。生产环境可通过 `VITE_AI_API_BASE` 指定 API 地址，并把前端源加入服务端 `CORS_ORIGINS`。

不填写模型配置也可启动服务：资料仍由 MarkItDown 转为 Markdown 并写入 `data/classroom.db`，学习包和对话使用降级结果。AI 解析的单文件上限为 500MB；`.env`、数据库和上传原件已排除版本控制。

## 演示流程

1. 教师进入“资料管理”，上传并选择资料。启用 AI 服务时，系统读取 PDF/PPTX/Word/文本等正文并生成学习包草稿；服务不可用时自动生成模拟内容。PDF 或图片可直接展示，其他格式需先导出为 PDF。
2. 教师查看“课前预习”与“课后复习”，每阶段默认生成 3 题并检查每名学生的真实逐题回答；重新解析会保留已有真实回答并清理旧模拟记录。
3. 学生登录，在“课前预习”完成全部选择题后提交；教师查看标记为“学生实际提交”的记录和正误。
4. 教师点击“开始上课”，学生切换到课堂互动，大屏展示选定课件。教师可使用“PPT 批注”或“展开白板”书写和清空当前画布层，笔迹不跨端同步或保存。
5. 点击提问按钮录音转写，或把提问按钮拖到课件区域；系统会合成当前课件页与板书快照，经多模态模型解析后出题。普通提问默认 15 秒，教师或大屏可提前停止。
6. 点击“小组讨论”，编辑问题并让学生选组。组长加入自己的组，可用文字或真实录音转写组织回答；教师点击“开始讨论 · 5 分钟”后回答自动同步。普通组员只能查看本组回答。手动结束或到时后按组整理总结，未回答组显示“暂无回答”。
7. 教师从“地理工具集”选择喀斯特地貌、太阳系、洋流、等高线或经纬图。工具覆盖教师课件区域，期间隐藏提问和讨论入口；点击“返回课中”恢复课件。工具选择不联动大屏。
8. 教师点击“结束上课”，学生切换到复习。返回教师课堂区域，在助教中点击“生成课堂报告”，然后点击“下载 / 打印 PDF”，在浏览器打印对话框选择“另存为 PDF”。报告是按当前状态渲染的示例视图，不会自动生成或保存独立 PDF 文件。

教师可在“班级管理”新增学生、改名和删除。学号不可手动修改，由当前名册最大编号加一生成；删除最大编号后可能复用编号。助教侧栏支持收起/展开；启用 AI 服务后，教师助教及学生学伴会检索课堂资料并返回来源引用。

## 数据与同步

| 存储位置 | 名称 | 保存内容 |
| --- | --- | --- |
| localStorage | `wh-students` | 学生名册与演示状态 |
| localStorage | `wh-classroom` | 课堂阶段、资料元信息、学习包、答题和讨论状态 |
| localStorage | `wh-messages` | 教师与助教消息 |
| localStorage | `wh-messages-cleared-at` | 助教历史消息的最近清空时间 |
| IndexedDB | 数据库 `wh-materials` / 对象库 `files` | 上传原始文件 |
| BroadcastChannel | 通道 `wh-classroom` | 完整课堂状态广播 |

课堂阶段、练习答案与讨论状态同步到同源标签页。学生名册、教师消息未专门实时广播；学生学伴对话、教师笔迹、工具选择和录音属于各页面本地状态。跨设备和跨浏览器没有同步；多个页面同时修改完整课堂状态可能互相覆盖，没有服务端并发控制。

### 重置演示数据

重置会删除当前源下的课堂记录和上传文件。先关闭该应用的其他标签页，在保留页面的浏览器开发者工具中：

1. 打开 Application/应用的 Local Storage/本地存储，删除 `wh-students`、`wh-classroom`、`wh-messages`、`wh-messages-cleared-at` 四个键。
2. 在 IndexedDB 中删除数据库 `wh-materials`；若提示占用，关闭应用页面后完成删除。
3. 重新打开应用，恢复八组共 34 名初始学生和课前状态，再上传资料。

仅删除课堂元信息不会清除原始文件；仅删除 IndexedDB 会使现有元信息指向缺失素材，需要重新上传。不同端口、开发与预览地址的数据分别保存，需在对应源下操作。

## 浏览器要求与已知限制

- 使用支持 localStorage、IndexedDB 和 BroadcastChannel 的现代浏览器。无 BroadcastChannel 时界面仍可运行，但标签页课堂状态不会实时同步；原文件读取缺失时页面会提示重新上传。
- 录音需要 localhost 或 HTTPS 与麦克风授权。语音识别依赖浏览器支持，短暂结束时会自动续连；不支持或权限失败时可用文字补充。停止后的音频可本机播放和下载，不持久化到数据库，不跨端同步。
- 资料管理采用课程文件夹：上传文件后可多选资料进行 AI 解析，仅 PDF 可指定为课中展示课件；生成的课前资料与测验、课中讨论题、课后资料与测验均可由教师编辑保存。课前与课后内容只有在教师点击“发送学生端”后才发布，学生端会以红点通知新资料。
- PDF 使用 PDF.js 在 Canvas 内渲染，不显示浏览器原生工具栏。文件只加载一次，翻页取消过期渲染；底部半透明翻页按钮支持首尾页边界与加载状态，页码同步到教室大屏。批注按文件和页码保留到教师页面关闭；PPT 需导出为 PDF 后上传。
- AI 服务未启动时，资料解析可回退为三题演示学习包；快照出题与习题 AI 分析会明确报错，不会伪装成模型结果。92%、88%、82% 与开始课堂提示中的预习完成率 100% 仍是演示值，不是实际学习统计。
- 当前 MVP 没有服务端认证、OCR、流式 ASR、WebSocket 跨设备同步、Web Search 工具或自动持久化报告；这些属于 `realAI.md` 的后续 P1–P3。原始需求差距见 [系统规格](spec/spec.md)。
- 数据保存在当前浏览器，没有备份或跨设备恢复；前端姓名学号校验与组长限制用于演示，不能作为正式部署的权限保障。
- `tools/` 内 HTML 含较多内嵌资源，生产构建可能提示输出块较大。应用依赖安装和浏览器语音服务可能联网，未验证所有工具的运行期请求，不承诺整套系统完全离线。

### 课堂分析与演示超时策略

- 课堂提问等待 5 分钟，小组讨论等待 20 分钟，均可手动提前停止。
- 教师端在作答结束后提交本次问题和真实回答给 AI；教师端和大屏共享分析结果。没有有效回答时显示数据不足，普通请求失败可重新分析。
- AI 生成入口默认等待上限为 30 秒；课堂报告为 120 秒。超时或网关返回 408/504 时，使用 `src/ai-demo.js` 中的「喀斯特地貌」预设内容，并明确显示演示标识。资料解析的上传和轮询共用 30 秒预算；课前预习、课中讨论题和课后复习可由教师检查，课前与课后内容可点击“发送学生端”发布，讨论题可在课中发起后送达学生端。普通服务错误不冒充真实分析。
- 课堂报告的待改进点以提问、回答及互动发言为文字依据，显示问题、依据和教学建议，无需课堂视频。
- 验证：`npm test`、`.venv/bin/python -m unittest discover -s tests -p 'test_*.py'`、`npm run build`。
