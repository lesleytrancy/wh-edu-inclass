## 一、 现状评估与能力差距分析 (Gap Analysis)

根据现有系统功能，各项需求的实现基础与改造点如下：

| **模块类别**           | **现有功能**                                                                           | **改造/升级缺口**                                                                                                                                           |
| ---------------------------- | -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **课堂资源生成 Agent** | 支持根据选定资料生成课前、课后学习任务及开放式讨论题                                         | 需要强化**严格的固定模板约束** （JSON 结构化输出），确保直接生成不需多轮交互的结果展示。                                                                    |
| **报告生成 Agent**     | 已具备“课前报告、课堂质量、课堂提问、课后总结、成长总览、新课标落实”六大分析入口及个人报告 | 部分指标（如新课标落实、成长总览）此前偏向示例数据，需完善真实数据聚合链路，并全面规范为**“总结性文本 + Chart.js 图文结合”**的形式。                            |
| **学伴 Agent**         | 提供启发式对话与测验分析                                                                     | 需要显式植入**“苏格拉底追问法”提示词链**，并为其接入**联网搜索工具** 。                                                                                   |
| **课堂助教 Agent**     | 支持基于 SQLite FTS5 检索资料对话，汇总学情与讨论纪要提供建议                                | 需绑定“点击开始上课”触发录音转写与纪要动态整理(前端同步显示格式化的实时会议纪要)，扩充知识边界（涵盖学科、课标及人培要求），并同样接入**联网搜索功能** 。 |

# 二、 AI 功能改造总体架构设计

1. **后端模型与工具扩展 (`server/app.py`)**：

* 引入结构化输出（Structured Outputs / JSON Mode）以满足两个工具类 Agent 的“固定模板”和“只展示结果”要求。
* 为两个问答型 Agent 扩展**联网搜索插件/API 接入**（如集成 Tavily Search 或主流大模型自带的 Web Search Tool），增强时效性与拓展性。

2. **前端交互与图表渲染 (`src/`)**：

* 报告模块全面集成 `Chart.js`，实现雷达图、时序图、柱状图与总结性段落的响应式布局。
* 问答 Agent 侧栏及学生端学伴界面支持搜索来源展示与苏格拉底式引导气泡。

## 三、 详细改造实施计划

### 模块一：工具类 Agent 改造（只展示结果，模板化生成）

#### 1. 课堂资源生成 Agent 改造

* **后端契约设计**：在 FastAPI 中增加专用路由 `/api/agents/resources/generate-template`，强制大模型输出固定 Schema：

```json
{
  "pre_study": { "objectives": "...", "tasks": ["..."] },
  "class_discussion": { "question": "...", "analysis": "...", "goal": "..." },
  "after_school": { "summary": "...", "exercises": ["..."] }
}
```

* **前端交互调整**：教师在资料管理界面点击“生成课堂资源”时，直接发起单次异步请求，加载完成后**不进入对话流，直接以只读结构化卡片展示结果**，支持一键确认并发布。

#### 2. 报告生成 Agent 改造

* **数据聚合逻辑**：在后端 `/api/agents/classroom/report` 路由中，聚合学生的真实测验作答、课堂互动积分、学伴发言、讨论小组会议纪要。
* **图文呈现升级**：
* **文本部分**：由大模型根据聚合数据生成六大板块的**总结性段落**（课前报告、课堂质量、课堂提问、课后总结、成长总览、新课标落实）。
* **图表部分**：使用 **Chart.js** 重新绘制课堂质量雷达图、提问层级分布柱状图、教学环节时序图等，做到严格的图文结合。

---

### 模块二：问答型 Agent 改造（对话交互 + 联网搜索）

#### 1. 联网搜索能力集成 (Common Infrastructure for QA Agents)

* **后端实现**：在 `server/` 目录下新增搜索服务模块，允许模型在遇到课外学科知识盲区、最新地理/教育资讯时自动触发联网搜索，并将搜索结果作为 Context 注入 Prompt。

#### 2. 学伴 Agent 改造（苏格拉底追问法）

* **上下文绑定**：自动获取学生在当前小节的“课前、课中、课后”测验结果与作答错题。
* **Prompt 策略改造**：设定系统提示词——*“你是一位善于启发式引导的学伴。严禁直接给出正确答案。当学生提问或回答时，必须使用苏格拉底追问法，通过反问、举例或拆解步骤引导学生自己得出结论。支持调用联网搜索辅助答疑。”*

#### 3. 课堂助教 Agent 改造（点击开课触发纪要 + 综合问答）

* **开课联动触发**：当教师在前端点击“开始上课”时，后端自动激活录音转写流，并在后台动态生成与更新课堂录音纪要。
* **多维问答扩展**：优化助教知识库检索，使其不仅能检索本地上传的 PDF/PPT 资料，还能结合实时录音纪要。
* **回答范围规范**：确保助教能够精准回答教师关于学情问题、学科问题、教学建议、新课标要求及学校人才培养方案（人培要求）的提问，并支持联网检索最新教研规范。
* 前端展示:前端同步显示格式化的实时会议纪要
