


# 武侯科教课中AI系统需求说明

## 1. 项目概述

本系统面向课堂教学场景，包含教师端与学生端。系统通过资源解析 Agent、课堂助教 Agent、学伴 Agent 协同，实现备课资料解析、课堂互动辅助、学习陪伴与课后总结。三个 Agent 通过 JSON 互通。

## 2. 全局要求

- **数据存储**：班级、学生数据存入本地数据库，建议采用 SQLite；资源解析生成物与内容需持久化；课堂总结报告需存储并支持下载。
- **学生登录校验**：学生输入姓名 + 学号，学号存在且姓名匹配方可登录；学号唯一、不可修改，从 08001 递增；教师可修改姓名、删除学生；系统模拟 3 名学生。
- **Agent 通信**：资源解析 Agent、课堂助教 Agent、学伴 Agent 通过 JSON 消息互通，消息应包含类型、发送方、接收方、课堂/班级 ID、学生 ID、内容、时间戳等。
- **课堂结束触发**：PPT 到达最后一页后显示“课堂结束”按钮，教师点击后触发课堂结束流程。
- **学生动态拉取**：课堂流程节点转换时自动拉取并总结全班动态，如课前转课中、发起提问、小组讨论、课堂结束等；可保留手动“拉取学生动态”按钮作为补充。
- **课堂总结报告**：课堂结束后自动生成，支持 PDF 下载，内容需包含学伴 Agent 与助教 Agent 的总结信息。

## 3. 教师端

### 3.1 主页面

- 左侧：PPT 展示区。
- 下方：功能操作区。
- 右侧：Agent 对话窗。

### 3.2 资源解析 Agent

- 教师上传备课资料。
- 自动解析为：
  1. PPT 大纲
  2. 课前预习内容
  3. 课中提问内容
  4. 小组讨论内容
- 教师确认后，发送给课堂助教 Agent 和学伴 Agent。
- 支持新建文件夹、上传、解析、生成物与内容存储。

### 3.3 课堂助教 Agent

- 点击“开始上课”后，自动发送课前预习总结。
- 课堂流程节点转换时，自动拉取学生动态并总结发送。
- 白板、发起提问、小组讨论流程结束后，自动发送总结。
- PPT 换页后，自动发送要点提示。
- 课堂结束后，自动生成 PDF 课堂总结报告，包含学伴 Agent 与助教 Agent 的总结信息。

### 3.4 教师端功能

- **白板**：在 PPT 上覆盖书写层，不改变 PPT 进度；包含书写、清空、关闭。
- **班级管理**：以卡片形式显示学生列表，最后一个卡片为加号，点击可添加学生；添加内容为名称 + 学号，学号自 08001 递增；点击卡片可修改姓名或删除学生；学号唯一且不可修改；数据存入本地数据库。
- **资源解析**：支持新建文件夹、上传、解析、生成物和内容存储。

## 4. 学生端

### 4.1 登录页

- 输入名称 + 学号登录。
- 按全局登录校验规则校验。

### 4.2 主界面

- 左侧：动态显示窗，跟随课堂流程显示。
- 右侧：学伴 Agent。

### 4.3 动态显示窗

- 教师端资源解析点击“确认资料”并“发送”：显示课前预习内容。
- 教师端点击“开始上课”：显示课中状态；教师端插入出题/讨论时显示对应内容；否则显示“请看大屏”。
- 教师端点击“课堂结束”：显示课后复习。
- 支持显示答题记录。

### 4.4 学伴 Agent

- 获取课前预习内容、课中提问内容、小组讨论内容。
- 课前主动推送预习消息。
- 左侧显示答题记录。
- 学伴 Agent 的总结信息纳入课堂总结报告。

## 5. 核心流程

### 5.1 课前

教师上传备课资料 → 资源解析 Agent 解析 → 教师确认并发送 → 课堂助教 Agent 和学伴 Agent 接收 → 学生端显示课前预习内容 → 学伴 Agent 推送预习消息并显示答题记录。

### 5.2 课中

教师点击“开始上课” → 助教 Agent 发送课前预习总结 → 学生端按课堂流程显示内容 → 节点转换时自动拉取学生动态 → PPT 换页发送要点提示 → 白板/提问/小组讨论结束后发送总结。

### 5.3 课后

PPT 到达最后一页 → 显示“课堂结束”按钮 → 教师点击 → 教师端显示课堂总结，学生端显示课后复习 → 自动生成 PDF 课堂总结报告，供教师下载。
