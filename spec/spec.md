# 武侯课教智慧课堂 · 现有系统规格

更新日期：2026-09-15。基线：`package.json` 版本 2.0.0 与当前 `src/`、`tools/`、`tests/` 实现。

## 概述与范围

系统以“喀斯特地貌”为示例课程，提供教师端、学生端和教室大屏，支持资料上传、预习与复习练习、课堂提问、小组讨论、Canvas 批注、地理教学工具和课堂报告。

本次工作是补齐现有系统文档。功能规格描述当前可观察行为；原始需求中的未实现项单独记录。本次不新增业务功能、不调整视觉样式、不迁移存储。交付物为本文件、`spec/plan.md`、`spec/tasks.md` 与根目录 `README.md`。

依据优先级：当前代码与测试决定已实现能力；[原始需求](../requierment.md)用于追溯目标及差距。根目录 [DESIGN.md](../DESIGN.md) 是 Eduplex 参考截图分析，与当前武侯课堂页面不同，不作为现有 UI 的验收标准。

## 用户与运行边界

| 角色 | 主要操作 | 当前边界 |
| --- | --- | --- |
| 教师 | 管理学生和资料、启动/结束课堂、发起互动、查看报告 | 无教师认证；浏览器本地演示 |
| 学生 | 姓名学号登录、提交练习、参与提问、加入讨论、使用学伴 | 姓名学号匹配为前端校验；没有服务端权限控制 |
| 大屏使用者 | 展示原始课件、互动回答、分析和讨论总结，手动停止互动 | 与其他端处于同一浏览器、同一源的标签页 |

同一源包含相同协议、主机和端口。跨浏览器、跨设备、隐私窗口与普通窗口之间不在当前同步范围内。界面提供课堂同步提示，但不代表存在网络服务。

## 用户场景

### US-01 · 教师准备并展示课程（P1）

教师打开工作台，上传图片或 PDF，查看模拟生成的预习/复习和学生答题概览，选择课中资料，点击开始上课并进行批注。学生端进入课堂互动，大屏展示选定资料。没有资料时教师不能开始上课。

对应 FR-01、FR-03 至 FR-09、FR-15、FR-19。

### US-02 · 学生练习与课堂提问（P1）

学生用林小满/08001 等账号登录，完成预习两道题并提交。教师看到实际记录，发起演示提问；学生点击普通提问麦克风获得模拟回答，大屏展示回答并在结束后展示示例分析。

对应 FR-02、FR-08 至 FR-10、FR-19。普通提问不验收真实语音识别或真实正确率。

### US-03 · 小组协作（P1）

教师创建讨论并修改题目，学生加入小组。组长在本组填写回答，组员查看。教师开始 5 分钟讨论，三端展示实时组回答，手动结束或超时后展示按组整理的总结。错误运行 ID、无效小组、非本组组长和结束后的更新不应改变回答。

对应 FR-11 至 FR-14、FR-19。

### US-04 · 工具演示与课堂复盘（P2）

教师选择地理 H5 工具进行演示，返回课中后结束上课；学生看到复习，教师打开报告并通过浏览器打印保存 PDF，助教和学伴均可进行预设内容对话。

对应 FR-07、FR-16 至 FR-18。

## 原始需求与实现差距

| 原始目标 | 当前状态 | 后续工作边界 |
| --- | --- | --- |
| SQLite 存储班级、学生、资源及报告 | localStorage 存元信息；IndexedDB 存原文件；无多班级模型 | 数据库及迁移另行规划 |
| 三个独立 Agent 通过类型、收发方、课堂/学生 ID 等 JSON 信封互通 | 单 React 应用与广播整份课堂状态；解析/助教/学伴主要预设逻辑 | Agent 协议、模型及后端未实现 |
| 资源文件夹、真实解析、PPT 大纲、确认并发送 | 无文件夹及确认发送步骤；上传自动生成固定学习包，不读取资料正文、不生成 PPT | 内容解析与审批流程未实现 |
| PPT 翻页提醒、最后一页显示课堂结束 | 浏览器展示上传 PDF/图片，没有应用级翻页与最后一页检测；授课中可直接结束 | 原生 PPT 渲染和页码联动未实现 |
| 节点转换自动拉取全班动态并生成真实总结 | 有阶段广播、预设开始/结束消息、按组整理讨论答案；无全班真实动态分析 | 92%、88%、82%、预习完成率 100% 等为演示值 |
| 真实语音提问、黑板截图识别、学生实时语音回答 | 普通提问全链路模拟；讨论编辑/组长录音接入浏览器原生 API | 真实 ASR/OCR 与提问分析未实现 |
| 课堂结束自动存储并下载完整 PDF 报告 | 结束时更新阶段和消息；点击报告临时渲染并 `window.print()` | 报告持久化、真实指标和独立 PDF 生成未实现 |
| 跨终端课堂联动与并发可靠性 | BroadcastChannel 同源同浏览器同步整份状态，无冲突解决 | 网络同步、会话隔离与并发控制未实现 |

## 假设与限制

“不齐”按“补齐”理解；输出语言为中文。规格面向当前演示系统，未实现功能不是本次开发任务。浏览器需要可用本地存储、IndexedDB 及 BroadcastChannel；语音功能受浏览器支持和在线识别服务影响，录音需 localhost 或 HTTPS。课堂状态采用整份对象同步，多个标签并行修改可能覆盖彼此；本地数据没有备份、版本迁移或服务端恢复机制。
